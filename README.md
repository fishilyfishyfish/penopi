# 페노피의 보드게임

판 위로 고개를 내민 낙서 **페노피**와 두는 보드게임 모음. 스케치북에 펜으로 그린 것 같은 화면에서, 페노피가 판 위를 알짱거리며
엔진이 실제로 계산한 형세를 보고 비꼬고, 가끔 잡학을 늘어놓는다.

## 게임 (19개)

말 옮기기
- **백개먼**: 주사위 굴려 먼저 다 빼면 이긴다. 더블링 큐브, 한 판 또는 3–11점 매치.
- **브레이크스루**: 말은 앞으로만 간다. 하나라도 상대 끝 줄에 닿으면 이긴다.
- **국제 드래프트**: 10×10 체커. 잡기는 의무, 가장 많이 잡는 쪽으로. 킹은 멀리 날아다닌다.
- **장기**: 궁을 외통으로 몰면 이긴다. 상차림은 골라서.
- **쇼기**: 잡은 말을 내 말로 다시 놓는 일본 장기. 페노피는 배우는 중.
- **체스**: 킹을 몰아넣으면 이긴다. 페노피가 제일 못하는 게임이라 연습 중.

잇기
- **오목**: 다섯 개 먼저 이으면 이긴다. 자유·흑 쌍삼 금지·렌주 중에서 고른다.
- **나인·식스·트웰브 멘스 모리스**: 셋을 한 줄로 세우면 상대 말 하나를 가져간다. 판 세 가지가 따로 있다.
- **육각잇기**: 육각형 칸에 돌을 놓아 내 변끼리 먼저 이으면 이긴다. 9·11·13줄.
- **얼티메이트 틱택토**: 틱택토 판 아홉 개. 내가 둔 자리가 상대가 둘 판을 정한다.

차지하기
- **오와레**: 씨앗을 뿌려서 2, 3개가 되면 가져간다. 25개 먼저.
- **리버시**: 끼우면 뒤집힌다. 끝났을 때 내 색이 많으면 이긴다.
- **점과 상자**: 선을 그어 상자를 닫으면 내 것. 3×3·4×4·5×5.
- **코네인**: 상대 돌을 뛰어넘어 치운다. 먼저 뛸 곳이 없어지면 진다.
- **수라카르타**: 고리를 따라 달려서 잡는다. 말을 전부 잡으면 이긴다.
- **하네프타플**: 왕을 구석으로 보내면 수비 승, 왕을 잡으면 공격 승. 7×7·11×11.
- **바둑**: 9줄, 중국식 계가. 페노피는 배우는 중.

페노피는 게임마다 제일 센 수준 하나로 둔다. 대국 전에 "봐주기"를 고르면 덜 열심히 두는데, 그 판은 전적에 안 적는다.
체스·바둑·쇼기는 연습 중이라 전적을 적지 않는다. 두다 만 판은 진 걸로 적는다.

백개먼 엔진은 [backgammon-palamedes](https://github.com/fishilyfishyfish/backgammon-palamedes)의 것을 그대로 가져와 WASM으로 빌드한다.
나머지 게임의 엔진은 모두 이 레포에서 새로 만든 순수 JS다(`<id>/engine.js`).
화면과 캐릭터는 [LOA_turk](https://github.com/fishilyfishyfish/LOA_turk)에서 왔다.

## 열기

GitHub Pages 주소로 연다. 한 번 열면 홈 화면에 앱처럼 추가할 수 있고, 그 뒤로는 인터넷이 없어도 열린다.

로컬에서는 WASM을 빌드한 뒤(`./tools/build-wasm.sh`) 아무 정적 서버로 연다(`python3 -m http.server`). 모듈 워커를 써서 파일을
직접 여는 `file://`로는 안 된다. 백개먼 말고는 WASM 없이도 열린다.

## 구조와 게임 추가

`CLAUDE.md` 참고. 게임 하나는 폴더 하나(`<id>/`)와 `games.js` 한 줄이다. 엔진마다 테스트가 `tools/test-<id>.mjs`에 있고 CI가 돌린다.
